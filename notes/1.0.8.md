## QG des agents 1.0.8

### Installer sur Mac sans blocage
- **Une seule ligne dans Terminal** installe le QG : elle télécharge la dernière version, vérifie son empreinte et la range dans `~/QG-des-agents`. macOS ne bloque plus `installer.command` (« Apple n'a pas pu confirmer… ») : ce qui est téléchargé par Terminal n'est pas mis en quarantaine.
- Le zip reste possible : le README explique quoi faire si macOS l'a bloqué.

### Ajouter un compte IA : le QG t'aide à installer ce qui manque
- **« Avant d'ajouter ce compte »** : sous le formulaire, la liste de ce qu'il faut sur ce PC pour cette IA, marqué ✓ (prêt) ou ✗ (manque). Une bulle « i » explique tout.
- **Un clic pour installer** :
  - Grok, Copilot, Gemini, Qwen, Kimi et OpenCode s'installent dans le dossier du QG (paquet npm officiel de leur éditeur, version épinglée) : rien ne change ailleurs sur ce PC ;
  - Cursor, Mistral Vibe (Mac) et Goose (Mac) : l'installateur officiel s'ouvre dans une fenêtre ; le QG vérifie tout seul toutes les 4 secondes ;
  - Codex : comme avant, dans le dossier du QG ;
  - Git, conseillé : winget sous Windows, outils d'Apple sur Mac ;
  - PowerShell 7 pour Copilot sous Windows (Windows n'a que la version 5.1) : winget, dans une fenêtre.
- **« Copier la commande »**, **« Page officielle »** et **« Vérifier à nouveau »** pour faire soi-même.
- **« Ajouter » reste grisé**, avec une explication, tant qu'il manque quelque chose d'obligatoire.
- Le QG trouve aussi un agent installé depuis son lancement, dans les dossiers où son installateur le range.

### Mac
- Ce qui n'existe pas encore sur Mac est grisé, avec son explication : la dictée locale (la dictée de macOS marche dans la zone de saisie).
- Réglages › Notifications explique la limite de macOS : la notification système apparaît au nom de « Éditeur de scripts ».

### Agents ACP : commandes corrigées
- **Qwen** : `qwen --acp` (`qwen serve` est un serveur HTTP, pas le mode ACP).
- **Gemini** : `gemini --acp`, la commande de sa documentation actuelle.
- **Cursor** : `cursor-agent acp` (le programme `agent` existe aussi chez Grok).
- **Kimi** : Kimi Code, le remplaçant de l'ancien Kimi CLI.

### Laisser le QG travailler sans le surveiller
- **Alertes sur ton téléphone** (Réglages › Dictée et notifications) : ton téléphone sonne quand un agent ou le DG a besoin de toi, quand un dossier est fini, quand une limite d'usage met le travail en pause, ou quand le QG a redémarré après un plantage.
  - Ça passe par ntfy, une application gratuite, sans compte. « Préparer mon téléphone » tire un nom de sujet long, impossible à deviner, et « Envoyer un essai » vérifie que tout marche.
  - Seul un titre court part, par exemple « T3 a besoin de ton avis ». Jamais le contenu de ton travail.
  - Chaque sorte d'alerte se coche à part. Coupé par défaut.
- **Le QG se relance tout seul s'il plante** : les dossiers en cours reprennent, le site et le téléphone le disent. Pas de relance après un arrêt voulu (Fermer, mise à jour, fenêtre fermée), ni s'il plante dès le démarrage, ni après 5 plantages en une heure.
- **Agent bloqué** : une tâche qui ne donne plus aucun signe de vie depuis 30 minutes est arrêtée, puis reprise dans la même conversation avec un conseil pour éviter le blocage. Après le 3e blocage, elle s'arrête et le DG décide de la suite. Une autorisation qui attend ta réponse ne compte pas.
- **Changement de compte Claude** : quand une limite d'usage fait passer une tâche sur ton autre compte Claude, elle garde sa conversation et reprend là où elle s'était arrêtée, au lieu de tout recommencer.

### Retrouver et réparer
- **Recherche dans tout l'historique** : une barre en haut de l'onglet Dossiers cherche dans tous tes dossiers, même archivés ou trop anciens pour la liste. Elle regarde la demande, les tâches, la synthèse du DG et tous les messages. Les accents ne comptent pas. « Ressortir » remet un vieux dossier dans la liste.
- **Annuler une suppression** : après « Supprimer », tu as 30 secondes pour cliquer sur « Annuler la suppression ». Le dossier n'est effacé pour de bon qu'ensuite.
- **Signaler un problème** (Réglages › À propos) : décris le souci ou ton idée. Le QG prépare un texte avec la version, le système et les dernières lignes du serveur, après avoir retiré tout ce qui est personnel (jeton, clés, adresses, dossiers, noms). Tu relis tout, puis tu l'ouvres sur GitHub ou tu le copies.

Déjà en 1.0.2 ou plus : la mise à jour s'installe toute seule au prochain lancement (ou Réglages › À propos › « Mettre à jour maintenant »).
Nouvelle installation sur Windows : télécharge **`QG-des-agents-1.0.8.zip`**, débloque-le (clic droit › Propriétés › Débloquer), extrais-le et lance **`installer.bat`**.
Nouvelle installation sur Mac : ouvre Terminal, colle cette ligne puis Entrée :
`curl -fsSL https://raw.githubusercontent.com/Ishine93/agents-hq/main/outils/installer-en-ligne.sh | bash`

**English:** Mac install in one Terminal line (no more Gatekeeper block on `installer.command`: files downloaded by Terminal are not quarantined). Adding an AI account now shows a "Before adding this account" checklist (✓/✗) of what this PC needs, with one-click installs: Grok, Copilot, Gemini, Qwen, Kimi and OpenCode install into the HQ folder from their publisher's official npm package (pinned version); Cursor, Mistral Vibe and Goose open their official installer; Git via winget or Apple's tools; "Add" stays greyed out until required items are there. On Mac, local dictation is greyed out with an explanation, and the notifications setting explains the "Script Editor" limit. ACP commands fixed: `qwen --acp`, `gemini --acp`, `cursor-agent acp`, Kimi Code. Also new: phone alerts through ntfy (off by default, only a short title is sent); the HQ restarts on its own after a crash, and an agent silent for 30 minutes is stopped and resumed in the same conversation; a task moved to your other Claude account keeps its conversation; search across every case, archived ones included; 30 seconds to undo "Delete"; "Report a problem" builds a scrubbed report you read before sending it.
