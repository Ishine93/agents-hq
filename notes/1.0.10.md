## QG des agents 1.0.10

Une version pour parler à un seul agent quand tu n'as pas besoin du DG, régler le QG en texte, garder le fil des très grosses demandes, et changer franchement de décor.

### Demande directe : un agent seul, comme dans Claude Code ou Codex
- Dans « Écrire au DG », la liste des dossiers propose **« Demande directe (un agent seul) »**. Ton message part tel quel à un agent, sans DG ni découpage en tâches, et il te répond comme dans Claude Code ou Codex.
- Juste à côté, tu choisis son **modèle** et sa **réflexion**. Le compte, le coût et les skills restent au même endroit. Le QG retient ton dernier choix pour chaque compte.
- L'agent travaille dans le projet de l'étage affiché, depuis un nouvel étage : l'**Isoloir**.
  - S'il lance ses propres sous-agents, ils s'installent aux postes d'à côté (3 au plus).
  - Trois décors au choix : studio feutré, cellule de prison, suite présidentielle avec jacuzzi.
- La conversation continue dans le même dossier, avec le même agent : choisis « Continuer la demande directe D12 ».
- Pour qui n'aime pas le principe du DG qui orchestre : le reste du QG s'utilise pareil.

### Des décors vraiment différents
- Pas juste d'autres couleurs : chaque décor a sa propre disposition, ses meubles, ses sols et ses murs. Il se choisit étage par étage dans Réglages › Étages :
  - **étages de projet** : labyrinthe de box, loft industriel, bateau pirate (en plus des cinq thèmes d'avant) ;
  - **Direction** : penthouse, repaire du méchant ;
  - **salle de pause** : plage, fête foraine ;
  - **salle de repos** : hôtel capsules, camping ;
  - **hall** : grand hall, tour de verre, hall au dinosaure ;
  - **sous-sol serveurs** : datacenter, labo du savant fou ;
  - **isoloir** : studio feutré, cellule de prison, suite présidentielle.
- **Le hall ressemble enfin à un hall d'immeuble**, avec une ou deux personnes à l'accueil derrière le comptoir, selon sa taille.
- **Un décor pour chaque étage** (Réglages › Étages) : la Direction, les salles communes, le hall, le sous-sol et l'isoloir aussi. Les agents y trouvent toujours leurs places.
- **Les agents ne se marchent plus dessus** : deux agents ne se superposent plus sur le même pixel. Ils marchent en file indienne et se décalent quand ils se croisent.

### Coût › Mode avancé : tout régler dans un fichier agents.md
- Pour qui préfère régler en texte, comme dans un AGENTS.md : un interrupteur **« Mode avancé »** dans Réglages › Général › Coût ouvre un fichier qui contient :
  - tout le réglage Coût, une ligne par valeur, avec les valeurs permises en commentaire ;
  - tes consignes au DG et par type de tâche.
- **Enregistrer** relit tout le fichier. Si une ligne est fausse, rien n'est enregistré et le QG te montre la ligne.
- **Réinitialiser** remet les valeurs d'origine sans toucher à tes consignes.
- C'est le même réglage que les cartes : changer l'un change l'autre. Le modèle et l'effort du DG et des tâches ne sont pas dans ce fichier, qui ne peut donc pas les baisser.

### Gardien du contexte (Coût)
- Sur une grosse demande, un détail décidé au début peut se perdre. Le nouveau réglage **« Gardien du contexte »** a trois choix :
  - **non** : comme avant.
  - **registre** : le QG tient le registre du dossier (ta demande, tes compléments et réponses, le plan, ce que chaque tâche a rendu). Chaque agent sait où le lire. Les agents apprennent aussi à lire un gros cahier des charges par sections plutôt qu'en entier. Presque gratuit : aucun appel à l'IA en plus.
  - **relecture par le DG** : en plus, le DG relit le rapport de chaque tâche terminée et corrige la suite du plan si le travail dérive. Le plus sûr, et le plus cher.
- En Max, le registre est tenu par défaut. En Économe et en Équilibré, rien ne change.

### Plusieurs IA : remis d'aplomb
- **Connecteurs MCP et autres IA** : le DG sait maintenant qui reçoit quoi.
  - Une tâche Claude reçoit les connecteurs de son compte ; une tâche Haiku n'en reçoit aucun.
  - Codex et les agents ACP reçoivent seulement les MCP de projet réglés sur « Auto ».
  - Le DG met donc sur Claude les tâches qui ont besoin d'un connecteur. La page Connecteurs MCP l'explique.
  - Les connecteurs de ChatGPT sur le web (Drive, Gmail…) restent sur chatgpt.com : Codex ne les reçoit pas.
- **Agents de la demande** : une tâche reçoit maintenant les connecteurs du compte qui la fait vraiment tourner.
- **Nombre de tâches max** : les valeurs de 13 à 30 de Personnalisé étaient ramenées à 12 sans rien dire. Elles comptent maintenant.
- **Image demandée par un agent Codex** sur son propre abonnement ChatGPT : il attendait 5 minutes sa propre place. Il reçoit maintenant tout de suite la raison.
- **Traduire les réflexions** ne faisait rien quand la demande tournait sur Codex ou un agent ACP. C'est réparé.
- Les explications de « Git sans demander », « Hors des projets » et du changement de compte disent maintenant ce qui vaut pour Claude, pour Codex et pour les agents ACP.

Déjà en 1.0.2 ou plus : la mise à jour s'installe toute seule au prochain lancement (ou Réglages › À propos › « Mettre à jour maintenant »).
Nouvelle installation sur Windows : télécharge **`QG-des-agents-1.0.10.zip`**, débloque-le (clic droit › Propriétés › Débloquer), extrais-le et lance **`installer.bat`**.
Nouvelle installation sur Mac : ouvre Terminal, colle cette ligne puis Entrée :
`curl -fsSL https://raw.githubusercontent.com/Ishine93/agents-hq/main/outils/installer-en-ligne.sh | bash`

**English:** Direct requests: pick "Direct request (a single agent)" in the request list and your message goes as is to one agent, with no director and no task split, as in Claude Code or Codex. You choose its model and reasoning next to it. It works from a new floor, the Booth, where its own sub-agents sit at the desks next to it; three decors: soundproof studio, prison cell, presidential suite with a hot tub. Truly different decors for every floor, including a lobby that finally looks like a building lobby, with one or two receptionists; agents no longer overlap on the same pixel and walk in single file. Cost › Advanced mode: the whole Cost setting and your instructions in one agents.md-style text file, checked line by line on save, with a reset. New "Context keeper" setting: a request log every agent can read, and optionally a review of every task report by the director to catch drift on very large requests. Multi-AI fixes: the director now knows which tasks get which MCP connectors (Claude only for claude.ai connectors; Codex and ACP agents only get project servers set to Auto), connectors follow the account that actually runs the task, Custom task limits up to 30 now apply, a Codex agent asking for an image on its own subscription gets an immediate answer instead of a 5-minute wait, and thought translation works when the request runs on Codex or ACP.
