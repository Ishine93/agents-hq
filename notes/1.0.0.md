## QG des agents 1.0.0

Première version partageable : un immeuble d'agents Claude en pixel art. Tu écris une demande au DG, il la découpe en tâches avec le bon modèle et le bon niveau de réflexion, et les agents travaillent en parallèle, un étage par projet.

### Installer (Windows 10/11)
1. Télécharge **`QG-des-agents-1.0.0.zip`** ci-dessous.
2. Clic droit sur le zip › Propriétés › coche **Débloquer** › OK, puis extrais-le (par ex. dans `C:\QG-des-agents`).
3. Double-clic sur **`installer.bat`** : Node.js portable et Claude Code s'installent dans le dossier, chaque téléchargement est vérifié (SHA-256).
4. Le QG s'ouvre dans ton navigateur avec une configuration guidée (langue, connexion Claude, dossiers de projets, mode de travail, dictée).

Il faut un abonnement Claude (Pro, Max, Team ou Enterprise) ou une clé API Anthropic. Git pour Windows est conseillé (l'installation le propose).

### Au programme
- Comptes Claude illimités, renommables, ajoutés depuis le site (menu « Ajouter un Claude ») ou `ajouter-un-compte.bat`.
- Plusieurs dossiers racines pour tes projets (jeux, IA, web…), détection automatique des projets, un étage par projet.
- Interface en français ou en anglais, et langue de travail des IA au choix.
- Consommation en temps réel : tokens du jour, limites du forfait (5 h, semaine, par modèle), détail par compte, modèle, étage et dossier, tokens économisés grâce au cache.
- Réglages complets dans le site : MCP par compte et par projet, prénoms et skins des agents, blagues du happiness manager (import / export Excel, CSV, JSON).
- Messages et documents en Markdown bien rendus (gras, tableaux, code…), visionneur des fichiers .md produits par les agents.
- Panneaux redimensionnables, taille du texte réglable.
- Dictée locale facultative (Whisper, sur ton PC) : `installer-dictee.bat`.
- Mises à jour : `mettre-a-jour.bat`.

Tout tourne en local (`127.0.0.1`), sans télémétrie. Les agents utilisent Claude Code avec ton propre compte : respecte les conditions d'utilisation d'Anthropic.
